# Success Plan (90 Days) – Template

**Customer Goal (plain words):** e.g., Fewer no-shows, faster confirmations, higher repeat visits.

**KPIs (pick 3):**
1) Same-day reply %
2) Show rate %
3) Repeat visit % (or time-to-proposal / utilization)

**Scope & Timeline**
- Weeks 1–2: Discovery, baseline, champions
- Weeks 3–4: Pilot at 2 sites; one-page dashboard; host/GM checklists
- Weeks 5–8: Scale to 5+ sites; first QBR
- Weeks 9–12: Feature deepening; renew/expand plan

**Cadence**
- Weekly: KPI snapshot + next-step
- Monthly: QBR (exec-friendly one-pager)

**Risks & Mitigations**
- Data hygiene → validation rules; mini training
- Staff turnover → 2-min Looms; playbooks
- Integration delays → alternate workflows; clear owners
